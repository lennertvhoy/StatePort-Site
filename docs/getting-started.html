Supported environment

Use a fresh Windows 11 AMD64 host, WSL2, stock Ubuntu 24.04, a normal sudo-capable user, and anonymous access to the public site and registry. StatePort does not support WSL1, ARM64, macOS, Docker Desktop, or other distributions in this release path.

uname -m
grep '^VERSION_ID=' /etc/os-release
ps -p 1 -o comm=

Expected output is x86_64, VERSION_ID="24.04", and systemd. The installer also requires curl, sudo, dpkg-deb, python3, sha256sum, and tar; it runs sudo apt-get update -o DPkg::Lock::Timeout=300, installs prerequisite packages with sudo apt-get install -y --no-install-recommends, then verifies the sealed Podman package plan before installing those packages with dpkg. A package-manager lock is retried once by the bootstrap; do not remove lock files.

Before installing

Save work in all WSL sessions. If PID 1 is not systemd, edit /etc/wsl.conf with administrator privileges, preserving existing settings. Set systemd=true in its existing [boot] section, or add that section if missing, then run wsl --shutdown from PowerShell and reopen Ubuntu. This stops every running WSL distribution. Keep several gigabytes free and do not run as root.

The one-line installer

The documented anonymous route is:

bash <(curl -fsSL https://lennertvhoy.github.io/StatePort-Site/download/install.sh)

When a supported release is available, the bootstrap checks the host, downloads signed metadata and pinned artifacts, verifies the pinned trust key and image manifests, asks for install-packages and install-exact, and requests sudo when installing system packages. It should finish with StatePort is installed and healthy, the loopback URL, and an install receipt path.

Alpha.16 does not reach that outcome on a fresh anonymous host. The published version is 0.1.0-alpha.16.

After a successful install

Open the printed http://127.0.0.1:<port>/ URL in a Windows browser. The web UI, API, worker, persistence, and execution host are local services. Use the printed reconciled port rather than guessing.

Use a template

Inspect the catalog and install a reviewed StudyState sample. For your own ProjectState, StudyState, or other valid StateSpec repository, read Templates. Keep the original repository and its own backup.

Receipts and state

Install receipt and updater state live below ~/.local/state/stateport-install, including bin/stateport-update. Application repositories and managed template copies are separate from replaceable images. Never share tokens, passwords, private URLs, or complete home directories.

If installation stops

Save the final refusal code, release version, and step. Alpha.16's missing predecessor signature slot is a release defect; an anonymous registry HTTP 401 is a package visibility blocker. Neither is fixed by rerunning, changing image tags, bypassing verification, or copying files into the state directory. Read Troubleshooting and Release status for a supported successor.

Report a problem

When reporting a problem, include the release version, final refusal code, environment checks, and last successful step. Remove tokens, passwords, private URLs, and personal file contents. Updates, backup boundaries, and uninstall explain lifecycle operations.
