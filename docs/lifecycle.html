Set up a known release

StatePort should install a specific release that can be checked, not whichever files happen to be newest.

Use the application

You start with the application's conversation, next action, and progress. Permissions, history, and technical details stay available without taking over the main screen.

Update or move

Before an update, StatePort should show what will change and protect your personal files. Moving to another computer should copy the application state and check it before you depend on the new copy.

Back up and recover

A backup should include the application data you need and a way to check it. Recovery should be tested in a separate location before replacing your working copy.

Current availability

These lifecycle features are the product direction. Alpha.16 is the current public-test candidate, but this page is not setup instructions. Check the release status.
