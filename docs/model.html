Application and personal copy

An application is the reusable workflow and interface. Your instance is your personal copy. It contains your private state, settings, permissions, and history.

The application can ask for access, but it cannot give itself permission or take ownership of your data.

Saved state

Saved state is the application's current record of your goals, progress, and decisions. Screens and summaries can display that state, but they do not silently replace it.

reusable workflow → application your goals → personal state generated summary → temporary view AI conversation → working context

Permissions

An application can use only the access you grant and the computer can safely provide. If something is missing, StatePort should stop or offer a limited mode instead of pretending the feature works.

Approvals and change records

You can allow routine work while requiring fresh approval for important actions. A change record shows what was requested, approved, changed, and checked.

File ownership

StatePort tracks which files belong to the application, which belong to you, and which can be rebuilt. That helps updates avoid overwriting personal work.
