Where Alpha.11 is meant to run

Alpha.11 is prepared for one Windows and WSL setup. Other platforms will need separate work.

Alpha.11 is the current public-test candidate. It provisions a pinned, verified Podman 5.4.2 package set from the signed release bundle, so the stock Windows 11 + WSL2 + Ubuntu 24.04 path does not depend on the distro's older Podman. Alpha.10 is rejected and install-disabled.

Alpha.11 requirements

  • Windows 11 on an x86-64 computer.
  • WSL2 with Ubuntu 24.04.
  • A normal Ubuntu user with sudo access.
  • Internet access.

Why support is narrow

StatePort uses local storage, Linux services, containers, and an AI command-line tool. A setup is only useful when all of those parts work together and your data survives a restart. We will add platforms only after testing the full journey.

Check before you start

Use the release status for current availability. Do not use older install instructions or try to adapt the Alpha.10 files to another platform.
