Alpha.16 requirements

  • Windows 11 on an x86-64 computer.
  • WSL2 with Ubuntu 24.04.
  • A normal Ubuntu user with sudo access.
  • Systemd enabled in WSL and Windows interoperability available.
  • Internet access and several gigabytes of free WSL disk space.

Quick preflight

Run these inside Ubuntu. They must report x86_64, Ubuntu 24.04, and systemd:

uname -m
grep '^VERSION_ID=' /etc/os-release
ps -p 1 -o comm=

The installer also verifies WSL2, Windows 11 build 22000 or newer, cgroup v2, subordinate UID/GID mappings, Quadlet, and the exact signed runtime inputs. If a requirement is missing, it refuses with a specific code instead of silently selecting a different setup.

Why support is narrow

StatePort uses local storage, Linux services, containers, and an AI command-line tool. A setup is only useful when all of those parts work together and your data survives a restart. We will add platforms only after testing the full journey.

Check before you start

Use the release status for current availability. Do not edit the bootstrap, mix older release files into Alpha.16, or relabel another platform as this release target.
