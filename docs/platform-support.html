Where Alpha.20 is meant to run

Alpha.20 supports one setup: Windows 11, WSL2, and Ubuntu 24.04 on an AMD64 computer. The installer checks that setup before it changes anything and stops with a message if it does not match.

Alpha.20 requirements

  • Windows 11 (build 22000 or newer) on an AMD64 (x86-64) computer.
  • WSL2, not WSL1, with stock Ubuntu 24.04.
  • systemd running as the first process inside Ubuntu.
  • A normal Ubuntu user, not root, who can use sudo.
  • Windows interoperability, so Ubuntu can run powershell.exe.
  • An internet connection during the install.

The installer makes more checks on the host while it runs and refuses with a message if something is missing. Troubleshooting explains each message.

Check before you start

Run the five commands in Step 2 of getting started inside Ubuntu, then run the dry run in Step 3. It checks the same requirements, verifies the signed manifests, and installs nothing.

What is and is not supported

  • Windows 11 + WSL2 + Ubuntu 24.04 on AMD64: the supported target. This is the only setup Alpha.20 is meant for, and the only one it has been measured on. See getting started.
  • WSL1: not supported. The installer stops with WSL2 is required; WSL1 and native Linux are not this release target.
  • Windows 10, or a Windows build older than 22000: not supported. The installer stops with Windows 11 build 22000 or newer is required.
  • Native Linux: not supported. The installer refuses it. Native Linux would need its own release path.
  • macOS, Docker Desktop, ARM64, other Linux distributions or Ubuntu versions: not supported. Not tested or packaged. The installer stops on ARM64 and on any distribution other than Ubuntu 24.04.

What was measured on this setup

The public one-line command installed Alpha.20 and reported it healthy on a fresh virtual machine running genuine Windows 11 25H2 with WSL2 and stock Ubuntu 24.04, five times. Not measured yet: surviving a Windows restart, importing templates on the installed product, uninstall and reinstall, every screen of the interface, and memory and disk use on a 16 GB laptop. The full lists are on current limitations.

Why support is narrow

StatePort uses local storage, Linux services, containers, and an AI command-line tool. A setup is only useful when all of those parts work together and your data survives a restart. We will add platforms only after testing the full journey.

Earlier releases

The Alpha.16 requirements named the same Windows 11, WSL2, and Ubuntu 24.04 setup. Alpha.16 is superseded, and its fresh installation was blocked, so do not use it. Use the current release named on the release status page, and do not mix files from different releases.
