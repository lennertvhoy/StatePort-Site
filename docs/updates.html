Update, repair, or remove StatePort deliberately.

Installed identity and user data are kept separate, so checking a release, applying a successor, removing services, and deleting state remain different actions.

Check the installed identity

~/.local/state/stateport-install/bin/stateport-update status

This reads the durable installed identity and updater state. It does not download or change a release.

Historical Alpha.16 rerun command

The intended rerun behavior recognizes the same release and its recorded resources. Alpha.16 currently fails its fresh signature check; this command is not a repair for that failure:

Historical command, currently blocked: retained for identifying the affected route; wait for a corrected release.

bash <(curl -fsSL https://lennertvhoy.github.io/StatePort-Site/download/install.sh)

Check the release

An update starts from a specific, signed release. StatePort checks that the files match that release before using them. It does not update from a moving "latest" download.

Keep trust changes separate

An update cannot quietly replace the key used to trust future releases. Changing that key requires a separate manual action.

Review before updating

StatePort should tell you that an update exists and show what will change. It waits for your approval before applying it. Automatic updates would be optional.

Check the result and roll back failures

After an update, StatePort waits for the application checks to pass. If they fail, it should return to the previous version and keep a record of the failure.

Keep a change record

Successful, refused, and failed updates should all leave a clear record. StatePort should not hide a failed update or retry risky work without asking.

Uninstall while preserving installer state

Download the immutable Alpha.16 installer, verify its signed-index digest, and ask it to remove only the recorded Alpha.16 runtime resources:

installer=$(mktemp)
curl -fsSL https://lennertvhoy.github.io/StatePort-Site/download/0.1.0-alpha.16/stateport-installer -o "$installer"
printf '%s  %s\n' 7930d29b04d169475c62cc104c5f0f4dab7a76fe7cda16c853e814b26eee319f "$installer" | sha256sum -c -
python3 "$installer" --uninstall --state-root "$HOME/.local/state/stateport-install"
rm -f "$installer"

Uninstall removes the recorded units, containers, and live runtime configuration but keeps the installer state and receipts needed to understand or resume the installation.

Purge is destructive

--purge additionally removes the installation's recorded retained state. Export or back up anything you need first. Purge is intentionally not presented as a copy-paste quick action.
