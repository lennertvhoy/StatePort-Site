What is StatePort?

StatePort gives AI-assisted applications a durable place to keep goals, progress, decisions, and history. That information lives in readable files on your machine instead of being trapped in one chat session.

Applications can ask an AI tool to help with work, but the tool does not own your data or decide its own permissions. In the StudyState Sample, StatePort keeps the current state, shows the proposed change, and records the result. Output from coding agents is recorded as a run result and is not promoted into application state.
