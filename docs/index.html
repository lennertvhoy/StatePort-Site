What is StatePort?

StatePort is a local platform with two cooperating planes. On the application plane, durable, user-owned applications keep named state, history, goals, context, and continuity over time — a study coach, a checklist, future domain applications. On the execution plane, a managed harness runs coding agents headlessly in environments you control, with supervision, permissions, isolation, cancellation, and evidence — including governed container deployments you approve before anything runs. Neither plane replaces the other.

Each application is a Stateware template: durable state files (Markdown and YAML) plus the cockpit scripts the agent is allowed to run. StatePort owns intent, authority, state, evidence, and acceptance; the agent owns execution behaviour and must never silently become the source of truth.
