What you will see

  1. A one-minute promise. StatePort is a place on your own computer where the work you do with AI can live.
  2. A project that keeps its own notes. The goal, what happened so far, and what needs your attention — not hidden inside a chat.
  3. Chatting with the helper. StatePort runs the AI coding agent through a managed local workspace. A declared job can use a sandbox or container when configured; the agent gets bounded tools and permissions, and asks before anything important changes.
  4. The project's memory. What is finished, what is still being checked, and what is only an experiment, so you know what to trust.
  5. The same project on a phone. The small-screen view stays readable.
  6. An honest note. This is a private-alpha preview that works with one AI coding tool so far, and there is no download yet.

How to read the claims

The video shows a working public-safe fixture and its recorded UI results. It does not turn that fixture into a downloadable software release; the release ledger and proof and roadmap keep those claims separate.
