Keep the application when the tool changes

AI tools and models behave differently. Your goals, files, decisions, and history should not disappear when you switch tools.

A session is not the application

A model session can help with current work, but it should not be the only place that holds your goals or progress. The application should remain understandable even when that session is gone.

Tools are not interchangeable

One tool may support cancellation, safe file access, or detailed usage reporting while another does not. StatePort should check those abilities instead of assuming every provider works the same way.

Current tool support

The Alpha.5 design uses a locally authenticated Codex command-line tool. OpenCode, direct API providers, and Pi are not supported by this release.

See platform support for the computer requirements and release status for availability.

What portability should preserve

  • Your application files and saved state.
  • Your goals, permissions, and history.
  • A clear record of which tool did the work.
  • An honest warning when a new tool lacks a needed feature.
