Availability boundary v0.1.0-alpha.5 is published as a signed WSL2 public-test candidate. Installation is enabled only for Windows 11 + WSL2 + Ubuntu 24.04 AMD64, and that path is compatible_unvalidated until the first real-host clean-install receipt exists. Human acceptance remains pending. The release ledger and download page are the current authorities; the Alpha.3 erratum remains historical.

Availability

  • Alpha.5 is published and cryptographically intact with an enabled public-test bootstrap, but it is not clean-installed, human accepted, independently reviewed, stable, or production qualified. The first WSL2 clean-install receipt is pending.
  • Alpha.2 is signed and published but superseded and not installable or accepted. Its web image omitted two runtime source trees and its bootstrap remains disabled.
  • The curated alpha.5 source archive is public; code and StateSpec artifacts are AGPL-3.0-or-later, and documentation is CC-BY-4.0. Canonical development Git and its history are private. The separately signed publicSnapshot Git identity is remotely resolvable from the public StatePort-Source repository; that public projection is not the private canonical development history.
  • There is no hosted service: StatePort is not offered as a managed or cloud product.

Product shape

  • StatePort is designed as a single-user, local product. The normal local service binds to the loopback interface only; multi-user, public-network, SSO, and managed-service operation are not qualified.
  • The user interface and documentation are English-only.

Platform and execution host

  • Alpha.5 has one signed target: wsl2-ubuntu2404-linux-amd64-rootless-podman-quadlet. It requires Windows 11 build 22000 or newer, WSL2 AMD64, Ubuntu 24.04, cgroup v2, rootless Podman, Quadlet, systemd user services, and subordinate UID/GID mappings.
  • WSL1 is refused before host mutation. Native Linux, other distributions, Docker Desktop, macOS, and ARM64 do not inherit this release's target or public-test status.
  • Capability checks and focused local validation exist, but no Windows 11 + WSL2 + Ubuntu 24.04 clean-install acceptance run exists yet.

Security and compliance

  • No independent security review, formal audit, or penetration test has been performed.
  • Release signatures are not uploaded to a public transparency log; verification relies on the pinned alpha release public key and its recorded fingerprint.
  • StatePort makes no GDPR, NIS2, or other legal or compliance certification claim.
  • There is no active public support or vulnerability-reporting route yet.

Deployments and updates

  • Container deployment is local-only and limited to projects that satisfy the documented contract (plus assisted proposals for recognizable Python, Node, and static-web repositories)—not “deploy anything”.
  • Deployment governance for unrelated projects is a host-CLI capability. Browser and preview capabilities described in source are not evidence of a production-qualified installation.
  • The signed Alpha.5 index describes an updater and pinned trust root; installed updater behavior remains bounded by the exact candidate and its receipts.
  • Trust-root rotation is a manual, out-of-band operator act; a release artifact can never rotate trust by itself.
  • Uninstall, purge, backup, restore, update, and rollback behavior require a successfully installed exact candidate and corresponding receipts. Alpha.2 has none.
  • There is no Azure or other cloud deployment; infrastructure code has no production-apply claim.

Applications

  • StudyState's canonical production release remains unresolved; alpha evidence uses local or synthetic inputs, not a production-eligible application release.
  • Study activity shown in the alpha is deterministic synthetic execution for testing—not evidence of tutoring quality or a live autonomous model.

Evidence

  • Alpha.5 has a published signed index, fresh-at-signing seven-image supply-chain evidence, independently re-derived candidate evidence, and a remotely resolvable public source snapshot. None substitutes for the pending real-host clean-install receipt.
  • Human acceptance, independent security review, stability, and production qualification remain open; Alpha.2 or Alpha.3 evidence was not transferred to Alpha.5 bytes.
  • No comparative or performance claim is made; none should be inferred from walkthroughs or documentation.
