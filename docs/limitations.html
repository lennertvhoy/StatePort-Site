Early alpha

StatePort is in early alpha. Do not use it for important data.

Computers

  • Alpha.16 targets Windows 11 with WSL2 and Ubuntu 24.04 on x86-64.
  • WSL1, ARM64, macOS, Docker Desktop, native Linux, and other Linux distributions are not part of this Alpha.16 release.

Local use

  • StatePort is designed for one person on one local computer.
  • There is no hosted service, team account system, or supported public-network setup.
  • The interface and documentation are available in English only.

Security

  • StatePort has not had an independent security review or penetration test.
  • Do not expose its local services to the public internet.
  • StatePort does not claim legal or regulatory certification.

Applications and features

  • StudyState works as an early-alpha application; it is not a finished or independently evaluated tutoring service.
  • ProjectState, StudyState, and portable StateSpec imports must be Git repositories under the installer-created allowlisted import folder.
  • Template import uses only committed content. Uncommitted and untracked files are not copied into the managed application.
  • Container deployment is for local, supported project shapes only.
  • Cloud deployment and managed hosting are not available.

Release evidence

Signed artifacts, reproducible image builds, vulnerability scans, an isolated clean-guest installation, an identical rerun, and lifecycle tests each establish a specific fact. None of them alone proves readiness for important data or routine production use. The release status keeps those categories separate.
