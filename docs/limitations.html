Availability boundary StatePort is a private alpha in product-owner testing. The release ledger remains the single source for what is publicly available — today, no download exists.

Availability

  • No public download, installer, or published release exists yet. A public download is in preparation and will be announced in the release ledger only when its evidence exists.
  • The implementation source is not public, and no product license decision has been published.
  • There is no hosted service: StatePort is not offered as a managed or cloud product.

Product shape

  • StatePort is a single-user, local product. The normal local service binds to the loopback interface only; multi-user, public-network, SSO, and managed-service operation are not qualified.
  • The user interface and documentation are English-only.

Platform and execution host

  • The only supported evaluation shape is Linux (x86-64) with rootless Podman. macOS, Windows, ARM64, and other platforms have no acceptance claim.
  • Codex CLI is the only execution provider exercised in the alpha. Pi is a reference direction, OpenCode is unqualified, and no provider is claimed equivalent to another.

Security and compliance

  • No independent security review, formal audit, or penetration test has been performed.
  • StatePort makes no GDPR, NIS2, or other legal or compliance certification claim.
  • There is no active public support or vulnerability-reporting route yet.

Deployments and updates

  • Container deployment is local-only and limited to projects that satisfy the documented contract (plus assisted proposals for recognizable Python, Node, and static-web repositories) — not “deploy anything”.
  • Upgrade and rollback between deployment revisions are not delivered yet; the alpha acceptance programme requires upgrade and rollback-or-truthful-refusal before a public release.
  • There is no Azure or other cloud deployment yet.
  • Backup and restore commands exist, but a restore cannot undo external side effects, and unknown or non-idempotent operations are never automatically retried.

Applications

  • StudyState's canonical production release remains unresolved; the alpha uses an exact local-alpha input, not a production-eligible release.
  • The alpha's study activity is deterministic synthetic execution for testing — not evidence of tutoring quality or of a live autonomous model.

Evidence

  • No human acceptance, clean-host installation proof, or independent validation of a release candidate has been recorded.
  • No comparative or performance claim is made; none should be inferred from walkthroughs or documentation.
