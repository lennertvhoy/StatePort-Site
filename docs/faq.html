What is StatePort?

StatePort gives AI-assisted applications a durable place to keep goals, progress, decisions, and history. That information lives in readable files on your own computer instead of being trapped in one chat session. An AI tool can help with the work, but it does not own your data or decide its own permissions: StatePort shows important proposed changes, asks for your approval, and records the result.

Alpha.20 is an early test release. It installs as a set of local services inside Ubuntu 24.04 on WSL2 (Windows Subsystem for Linux) on Windows 11, and you open it in your web browser at an address on your own computer. Read why StatePort exists or the core model for the idea, or install it to look for yourself.

Is it safe?

Treat it as untested software. StatePort is in early alpha and has not had an independent security review. Do not use it for important data, and try it on a computer or virtual machine where a mistake would not matter.

What the design and installer do to limit risk:

  • The installer checks the host first, then downloads each file and compares it with a fixed checksum before using it. It also verifies signed release files.
  • It asks for two explicit confirmations, and you type each confirmation word yourself.
  • The address it prints is 127.0.0.1, your own computer. Do not expose it to the internet.

What it changes on your machine: it installs system packages and services inside the Ubuntu distribution you run it in, and it registers one Windows scheduled task named StatePortKeepAlive. There is no supported one-command uninstall in this alpha, so read updates and removal before installing on a computer you care about. More detail is in security and privacy.

Where does my data live?

On your own computer, inside the Ubuntu (WSL) distribution where you installed StatePort. It is not stored in a StatePort cloud service. The installer keeps its receipts and installation records in ~/.local/state/stateport-install in that Ubuntu user's home folder. Application content is held by StatePort's local services in the same distribution, and where every file lives has not been written up for Alpha.20 yet.

Because it all sits inside one distribution, removing that distribution would remove it. Keep your own backups, and read backup and recovery for what the product intends to offer and what it does not promise.

Does it need internet?

  • To install, yes. The installer downloads release files from this site and from GitHub, and downloads the container images anonymously.
  • After install, StatePort runs as local services on your computer and you open it at a local address. Whether every feature works with no connection has not been measured.
  • Connecting an AI tool does need internet. A request to a remote provider can send task context to that provider; see before connecting an AI tool.

What can I not do yet?

  • Use anything other than Windows 11 with WSL2 and Ubuntu 24.04 on AMD64. WSL1, ARM64, macOS, native Linux, Docker Desktop, and other distributions are not supported.
  • Uninstall or reinstall with a tested, supported command. Neither has been measured yet.
  • Rely on StatePort surviving a Windows restart. Restart survival has not been measured.
  • Count on template import (ProjectState, StudyState) working on the installed product. It is designed to, and it has not been measured there yet.
  • Update in place or roll back. There is no supported in-place update or rollback in this alpha.
  • Use it for a team, as a hosted service, or across the public internet. It is designed for one person on one local computer.

The complete measured and not-measured lists are on current limitations.

How do I report a bug?

Open an issue on GitHub. Include the release (0.1.0-alpha.20), the step you were on, and the exact message you saw. If the installer printed a refusal record: path, attach that file after checking it for anything private. Remove tokens, passwords, private URLs, and personal file contents from anything you share. Do not post secrets, and do not post details of a suspected vulnerability in public: there is no private reporting address yet, so open an issue that says a security issue exists and leaves the details out. Troubleshooting lists what helps most.

Who builds it?

StatePort is an independent project by Lennert Van Hoyweghen. AI coding agents assisted the implementation under his direction. The public source for the release is in the StatePort-Source repository: code and StateSpec files use AGPL-3.0-or-later and documentation uses CC-BY-4.0. The technical release files page has the signed release index and source archive.
