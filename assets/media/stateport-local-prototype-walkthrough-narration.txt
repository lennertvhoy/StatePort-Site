StatePort starts with named applications, not a blank chat. This private-alpha
fixture shows ongoing work with its own purpose, durable state, decisions, and
history.

The application plane provides purpose and continuity. StatePort owns intent,
authority, canonical state, evidence, and acceptance. Those facts do not belong
to an agent session.

Conversation is one view inside the application. The execution plane is
separate: the harness runs an authorized task and returns observations and
candidate output, but it does not own accepted state.

The source view says whether an application source is verified. A development
candidate can provide isolated-test evidence, but it does not silently become a
canonical release or production install.

The same application list remains readable on a small screen. This is a local
interface view, not evidence of a separate mobile release.

This private alpha has one exercised provider path: Codex in supervised-direct
mode. Other providers are not qualified by this walkthrough, and there is no
public software download yet.
