Do not install Alpha.3

Alpha.3 contains known bugs. Its installer is disabled.

Erratum

What happened What should I do next? Technical files Download page Release status

What happened?

Alpha.3 has two known problems:

  • Its installer can no longer pass the release checks.
  • Its installer and runtime do not complete the full StatePort setup correctly.

What should I do next?

  • Do not run an old Alpha.3 install command.
  • Check the release status for current availability.
  • If you tried Alpha.3, do not keep important data in it.
  • If you found a bug, open an issue.
