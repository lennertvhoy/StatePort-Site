Nothing on this page is a release. The alpha label means: no production-readiness claim, no multi-user or hosted operation, no independent security review, and no comparative or performance claim.

Prerequisites

  • Ubuntu 24.04 LTS on x86-64 (AMD64) — the only supported evaluation shape. macOS, Windows, ARM64, and other platforms have no acceptance claim.
  • Rootless Podman — StatePort runs its services as an unprivileged user; no root daemon is required.
  • No source checkout — the installer is self-contained; you do not clone the implementation repository (which is not public) to install.

Install and update lifecycle

  • Install — the verified installer pins the release trust root out of band, pulls the digest-pinned images, and starts the services with health checks. The full install will be tested from a clean environment before the version is published.
  • Update policy — the alpha default is notify: you are told an update exists and nothing is applied without your authorization. Applying an update is approval-gated and health-gated, with automatic rollback to the retained predecessor if the successor is unhealthy. Details: how updates work in the alpha.
  • Backup — backup and restore commands exist for the durable state. A restore cannot undo external side effects, and unknown or non-idempotent operations are never automatically retried.
  • Uninstall — guided uninstall stops the services and preserves all data; purge also removes the data and refuses unless you confirm the exact installed identity ID. Purge does not remove the Podman networks the installation created.

Alpha limitations

  • Single local user on a single machine; the services bind the loopback interface only. Multi-user, public-network, SSO, and managed-service operation are not qualified.
  • No hosted service: StatePort is not offered as a managed or cloud product, and no Azure or other cloud deployment exists.
  • No independent security review, formal audit, or penetration test has been performed.
  • Model-backed execution requires a separately authenticated execution host; the no-checkout install runs StudyState through the bundled deterministic synthetic executor.
  • Human acceptance of the candidate is pending; reviews so far are internal multi-agent reviews with independence not established.
