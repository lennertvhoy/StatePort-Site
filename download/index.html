Alpha.16 remains published, but fresh installation is blocked by a known signature-check failure. Anonymous image downloads also fail with HTTP 401 because the release image registry packages are private. Fixing the signature check alone will not complete installation. Wait for a corrected, qualified release; repeating this installer does not repair either failure. Published files remain available for inspection.

StatePort is in early alpha. Do not use it for important data. Use test data and keep your own backups. Alpha.16 is intended for one person on one local Windows 11 laptop; it is not production software.

Before you start

  • Windows 11 on an x86-64 computer.
  • WSL2 with Ubuntu 24.04.
  • A normal Ubuntu user with sudo access.
  • Internet access, sudo, and several gigabytes of free WSL disk space.
  • Systemd enabled inside WSL.

Run the three environment checks and see the complete walkthrough.

Affected Alpha.16 command

Open Ubuntu 24.04 in WSL2 and run this as your normal Ubuntu user:

Historical command, currently blocked: retained for identifying the affected route; wait for a corrected release.

bash <(curl -fsSL https://lennertvhoy.github.io/StatePort-Site/download/install.sh)

The installer checks the host before mutation, verifies the signed release and exact image manifests, shows the package and installation plans, and asks for two explicit confirmations. A successful run prints StatePort is installed and healthy, the local URL, and the durable receipt path.

After installation

  1. Open the printed http://127.0.0.1:…/ address in your Windows browser.
  2. Install the reviewed StudyState sample from Catalog, or place a Git repository below /var/lib/stateport/imports.
  3. Use Catalog → Import a local repository to review its exact commit and create an isolated ProjectState, StudyState, or generic StateSpec workspace.
