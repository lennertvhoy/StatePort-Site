StatePort runs on Linux on Intel/AMD with rootless Podman. The installer checks your system, downloads signed images, checks every signature, and asks before it installs.

What works

  • Ubuntu 24.04 — tested, works.
  • Fedora 44 — works, not fully tested.
  • Debian, Arch, and other distros — not yet.

The installer decides by checking what your machine can actually do, not by its distro name. A matching machine we haven't run a clean install on is marked "works, not fully tested".

What the installer does

  1. Checks your system is compatible.
  2. Downloads the signed images and verifies every signature.
  3. Asks you to type install before it changes anything.

If your system is not compatible, it stops and changes nothing. Read the installer script before you run it if you like.

Honest disclaimer. This is alpha software. It has not been security-audited or tested for production. Don't run it anywhere that matters yet.

Alpha.2

v0.1.0-alpha.2 is superseded and disabled. Use alpha.3. Do not install alpha.2. Its signed files stay online for inspection — they are not changed or relabelled — but its installer stays disabled because the packaged web image was missing required source trees.

Inspect the alpha.2 signed index or read the release status page.
