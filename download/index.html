One-command install

Run this as your normal user, not as root:

curl -fsSL https://lennertvhoy.github.io/StatePort-Site/download/0.1.0-alpha.2/install.sh | sh

The script shows the exact install boundary and asks you to type install before proceeding. It never sends the installer through sudo; sudo is used only when you explicitly approve installation of missing Ubuntu prerequisites.

What the bootstrap verifies

  1. Checks Linux AMD64, a non-root session, and the current signed host baseline.
  2. Downloads the immutable alpha.2 installer and verifies its published SHA-256.
  3. Downloads and verifies the release-index signature bundle and the exact Cosign v3.1.2 binary.
  4. Pins the release public-key ID and DER-SPKI fingerprint.
  5. Invokes the signed installer with exact versioned URLs. The installer then verifies the release index, every artifact, every image signature, and every digest before starting rootless Podman services.
  6. Writes an install or refusal receipt under your StatePort state directory.

Linux support

Current signed candidate: Ubuntu 24.04 AMD64, cgroup v2, systemd user services, rootless Podman 4.9.3 or newer, and Quadlet.

The container workloads are not inherently Ubuntu-specific. The Ubuntu check is an unnecessarily narrow release-contract boundary in alpha.2. It will be replaced in a later signed candidate by capability detection and a clean-install matrix covering multiple Linux distributions. Alpha.2 itself remains immutable: this page does not silently bypass or rewrite its signed target.

What is and is not proven

  • Published: signed index, versioned artifacts, seven digest-pinned GHCR images, image signatures, SBOMs, scan dispositions, and source/export evidence.
  • Pending: clean install from the public command, restart reread, and the owner’s exact acceptance or rejection verdict.
  • Not claimed: independent security review, production qualification, hosted or multi-user operation, ARM64, macOS, Windows, or cross-distribution acceptance.
