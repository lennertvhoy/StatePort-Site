Before you start

  • Windows 11 on an x86-64 computer.
  • WSL2 with Ubuntu 24.04.
  • A normal Ubuntu user with sudo access.
  • Internet access.

Install Alpha.10

Recommended first step: check your computer without changing it. In an Ubuntu 24.04 WSL2 terminal, as your normal user, run:

(umask 077; tmp="$(mktemp)" && trap 'rm -f "$tmp"' EXIT HUP INT TERM && curl --fail --location --silent --show-error --proto '=https' --tlsv1.2 --output "$tmp" https://lennertvhoy.github.io/StatePort-Site/download/install.sh && test "$(wc -c < "$tmp")" -eq 17774 && printf '%s %s\n' 'afb807280e1588ce4903be79649a7b7dd69026177b18a7a98a95b01f54f74d5d' "$tmp" | sha256sum --check --status - && /bin/sh -n "$tmp" && /bin/sh "$tmp" --materialization-preflight)

The preflight downloads the installer bootstrap, verifies its exact size and pinned SHA-256, checks its shell syntax, and verifies the setup plan. It does not install anything: packages, root files, images, and the installer are not changed or executed.

Then install. Run this exact command in the same terminal:

(umask 077; tmp="$(mktemp)" && trap 'rm -f "$tmp"' EXIT HUP INT TERM && curl --fail --location --silent --show-error --proto '=https' --tlsv1.2 --output "$tmp" https://lennertvhoy.github.io/StatePort-Site/download/install.sh && test "$(wc -c < "$tmp")" -eq 17774 && printf '%s %s\n' 'afb807280e1588ce4903be79649a7b7dd69026177b18a7a98a95b01f54f74d5d' "$tmp" | sha256sum --check --status - && /bin/sh -n "$tmp" && /bin/sh "$tmp")

The install command downloads the bootstrap to a private temporary file, verifies its exact size and pinned SHA-256, and checks its shell syntax before running it. There is no pipe-to-shell stage.

If the install asks for your password, it is your own computer asking for the administrator rights needed to set up StatePort's helper program.
