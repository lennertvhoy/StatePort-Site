Alpha.2 is superseded

v0.1.0-alpha.2 is superseded — use alpha.3. Its immutable signed artifacts remain online for cryptographic inspection, but its bootstrap remains disabled because the packaged web image omitted required runtime source trees. Do not install alpha.2.

Inspect the alpha.2 signed index or read the release ledger. Alpha.2 files are not rewritten or relabelled.
