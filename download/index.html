Install Alpha.5 on Windows 11 + WSL2

This is an unqualified public-test candidate. v0.1.0-alpha.5 is signed and installation is enabled only for Windows 11, WSL2, AMD64, and Ubuntu 24.04. No real-host clean-install receipt exists yet; the first run is owner testing, not acceptance or production qualification.

Alpha.5 has one exact target: wsl2-ubuntu2404-linux-amd64-rootless-podman-quadlet. It refuses WSL1, native Linux, other distributions, ARM64, missing systemd, and older Windows builds before release installation begins.

Before you start

  • Windows 11 build 22000 or newer on an Intel or AMD 64-bit computer.
  • Administrator access in PowerShell to install or update WSL.
  • A normal, non-root Ubuntu 24.04 user with working Windows interoperability and sudo.
  • Internet access to GitHub Pages, GitHub releases, Ubuntu package repositories, and the public ghcr.io/lennertvhoy image packages.

1. Prepare Windows and WSL2

Open PowerShell as Administrator and run:

wsl --update wsl --install -d Ubuntu-24.04 wsl --list --verbose

If the VERSION column shows 1 for Ubuntu 24.04, convert it and check again:

wsl --set-version Ubuntu-24.04 2 wsl --list --verbose

Open Ubuntu 24.04 from the Start menu or run wsl -d Ubuntu-24.04. Finish Ubuntu's first-user setup, then enable systemd inside Ubuntu:

printf '[boot]\nsystemd=true\n' | sudo tee /etc/wsl.conf

Return to PowerShell, restart WSL, and reopen the distribution:

wsl --shutdown wsl -d Ubuntu-24.04

Back in Ubuntu, confirm systemd is PID 1 and install curl if needed:

ps -p 1 -o comm= sudo apt-get update && sudo apt-get install -y curl

The first command must print systemd. If it does not, stop and fix the WSL systemd setup before continuing.

2. Run the signed public-test installer

In the fresh Ubuntu 24.04 shell, as your normal user, run this exact command:

curl -fsSL --proto '=https' --tlsv1.2 https://lennertvhoy.github.io/StatePort-Site/download/0.1.0-alpha.5/install.sh | sh

The bootstrap checks Windows 11, WSL2, AMD64, Ubuntu 24.04, systemd, Windows interoperability, and sudo before it asks for permission. Review the prompt and type exactly install at Type install: to continue. It then requests sudo authentication, installs host prerequisites, verifies the release index, trust key, predecessor signature, installer, provisioner, updater, and seven image signatures, and provisions the rootless execution host.

A completed bootstrap ends with StatePort 0.1.0-alpha.5 installed successfully. Retain the receipts under ~/.local/state/stateport-install/ and /var/lib/stateport-provisioning/receipts/; they are the evidence needed to decide whether this first real-host run qualifies.

Honest disclaimer. Alpha.5 is intended for a controlled first-host test. It is compatible_unvalidated, not clean-installed, owner-accepted, independently security-reviewed, stable, or production-ready. Do not use it for important data or expose its local services to a network.

Older releases

Do not install Alpha.2 or Alpha.3. v0.1.0-alpha.2 is superseded and disabled because its packaged web image omitted required source trees. v0.1.0-alpha.3 remains signed and byte-intact but install-disabled because its evidence expired and its released installer/runtime defects require a successor. Their immutable files remain online for inspection.

Read the historical Alpha.3 erratum, inspect its signed index, or inspect the Alpha.2 signed index.
