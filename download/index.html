Download / Linux alpha

Alpha.2 installation is paused.

The signed v0.1.0-alpha.2 artifacts remain available for inspection, but the install entrypoint is disabled because the packaged web image omits two runtime source trees required by the application server.

Status

Installation paused Known defect Linux boundary Inspect artifacts Evidence status

Do not install alpha.2. No successful install receipt exists. The candidate is published and signed, but it is known defective and cannot be accepted as-is. A corrected successor must be rebuilt, re-signed, re-published, and clean-installed with fresh evidence.

Installation disabled

The former one-command URL now refuses immediately with a clear diagnostic. This prevents new users from pulling several large images for a candidate that cannot complete.

Alpha.2 is immutable. The published installer, signed release index, and image digests are not being rewritten or relabelled as repaired.

Known packaged-image defect

  • The web application imports the installed updater control plane and the preview gateway.
  • The signed alpha.2 web image omitted both corresponding source trees from its final-image allowlist.
  • The web service therefore cannot start from the signed image, so the installer cannot obtain a complete healthy-service receipt.
  • A source correction exists for a successor, but no corrected image, signature, release index, or install evidence has been published yet.

Linux boundary

Alpha.2 signed target: Ubuntu 24.04 AMD64, cgroup v2, systemd user services, rootless Podman 4.9.3 or newer, and Quadlet.

The defect is in the packaged web image, not a Fedora-specific incompatibility. A Fedora 44 unsupported-host investigation exposed it, but that run is diagnostic evidence only and does not qualify Fedora. A future candidate must use capability detection and earn clean-install receipts for every distribution it claims.

What is and is not proven

  • Published and verified: signed index, versioned artifacts, seven digest-pinned GHCR images, image signatures, SBOMs, scan dispositions, and source/export evidence.
  • Known failure: alpha.2’s packaged web image is incomplete; no successful installation receipt exists.

  • Not claimed: human acceptance, independent security review, production qualification, hosted or multi-user operation, ARM64, macOS, Windows, or cross-distribution acceptance.
