Before you start

  • Windows 11 on an x86-64 computer.
  • WSL2 with Ubuntu 24.04.
  • A normal Ubuntu user with sudo access.
  • Internet access.

Alpha.11 installer

Alpha.11 is available for a first public test and installation is enabled.

Run the one-command installer in your Ubuntu 24.04 WSL2 terminal:

bash <(curl -fsSL https://lennertvhoy.github.io/StatePort-Site/download/install.sh)

Alpha.11 installs a pinned, verified Podman 5.4.2 package set from the signed release bundle, so a stock Ubuntu 24.04 install does not receive the distro's older Podman 4.9.3.
