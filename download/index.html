Current status Why disabled Verification details Erratum Alpha.2 Release status

Alpha.3 targets Linux on Intel/AMD with rootless Podman. The signed release and its verification material stay online below for inspection, but there is no working install path today.

Why installation is disabled

  • Signed freshness evidence has expired. All seven signed image scans and vulnerability databases are older than the 24-hour maximum age the installer enforces, so current-time verification refuses every image before anything is installed.
  • Known installer and runtime defects. The committed installer does not provision or protocol-health-check the declared execution host, and goal execution in this candidate is synthetic. These defects require a successor release; they cannot be fixed by re-running this one.
  • Earlier receipts are not current proof. Historical local install receipts for Ubuntu 24.04 and Fedora 44 were recorded while the freshness evidence was valid. They do not establish that the release is installable now.
  • No acceptance exists. Owner acceptance, independent security review, and production qualification have not happened.

What to do next: wait for a successor release. The release status page and the alpha.3 erratum carry the current truth when one is published.

Honest disclaimer. This is alpha software. It has not been security-audited or tested for production, and it currently cannot be installed at all. Don't run it anywhere that matters.
