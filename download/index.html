Alpha.5 installation temporarily disabled

Alpha.5 has one exact target: wsl2-ubuntu2404-linux-amd64-rootless-podman-quadlet. It refuses WSL1, native Linux, other distributions, ARM64, missing systemd, and older Windows builds before release installation begins.

Before you start

  • Windows 11 build 22000 or newer on an Intel or AMD 64-bit computer.
  • Administrator access in PowerShell to install or update WSL.
  • A normal, non-root Ubuntu 24.04 user with working Windows interoperability and sudo.
  • Internet access to GitHub Pages, GitHub releases, Ubuntu package repositories, and the public ghcr.io/lennertvhoy image packages.

1. What failed

The owner reports that the first Windows 11 + WSL2 + Ubuntu 24.04 AMD64 command completed its prerequisite package step, then Dash exited with an unterminated quoted string before the Python StatePort installer ran. No install receipt was produced. This is a failed partial bootstrap attempt with prerequisite side effects, so that distribution is not clean-install evidence.

Review of the reported failure found that the streamed shell received only 4,096 bytes of the valid 8,971-byte bootstrap. The complete immutable bootstrap and signed release payload remain intact; the defect is the promoted pipe-to-shell transport, not evidence that the signed payload is defective.

2. Containment and repair status

Installation temporarily disabled. No executable Alpha.5 install command is published on this page while containment is active.

The replacement transport first downloads the complete immutable bootstrap to a private temporary file, requires a successful transfer, checks its exact 8,971-byte size and pinned SHA-256, and runs /bin/sh -n. Its installer-executing form remains held back until an owner-run, non-executing exact-WSL2 transport probe passes review. Temporary files are removed on success or failure.

Honest disclaimer. Alpha.5 is intended for a controlled first-host test. It is compatible_unvalidated, not clean-installed, owner-accepted, independently security-reviewed, stable, or production-ready. Do not use it for important data or expose its local services to a network.

Older releases

Do not install Alpha.2 or Alpha.3. v0.1.0-alpha.2 is superseded and disabled because its packaged web image omitted required source trees. v0.1.0-alpha.3 remains signed and byte-intact but install-disabled because its evidence expired and its released installer/runtime defects require a successor. Their immutable files remain online for inspection.

Read the historical Alpha.3 erratum, inspect its signed index, or inspect the Alpha.2 signed index.
