Try it · help me test

Run one command. Tell me what breaks.

StatePort Alpha.20 is an early alpha, built by one person, in the open. If you have a Windows 11 computer with WSL2 and Ubuntu 24.04, you can install it with one command and help me find what still fails. Use a test machine and test data only.

01 / CHECK

Check the machine

Windows 11 on a 64-bit Intel or AMD PC, WSL2 with Ubuntu 24.04, systemd switched on, and a normal Ubuntu user that can use sudo. The download page lists each check.

02 / RUN

Run one command

Open Ubuntu and paste this as your normal user. Along the way it asks for your sudo password and for two typed confirmations.

bash <(curl -fsSL https://lennertvhoy.github.io/StatePort-Site/download/install.sh)

Want a dry run first? Add --transport-probe at the end. It installs nothing.

03 / OPEN

Open the local address

A successful run prints StatePort is installed and healthy and a local address such as http://127.0.0.1:18012/. Open it in your Windows browser.

Why it matters

Three things stay true.

01

Your work stays yours

Goals, decisions, and history live in readable files on your own machine — not in a session locked inside someone else's chat.

02

Continuity is designed for restarts

State is saved on disk, not held in a chat window, so a new session, a different model or a restart starts from what was saved.

03

Change stays reviewable

Important changes are proposed first. You can inspect the result and see what happened.

Current availability

Alpha.20 is the current early alpha.

StatePort is in early alpha. Do not use it for important data.

Alpha.20 installs on Windows 11 with WSL2 and Ubuntu 24.04 from one command. That command installed StatePort successfully, and it came up healthy, five times on fresh Windows 11 virtual machines. After you sign in to Windows, a small background task keeps StatePort reachable even after the last WSL window is closed.

The release installs the web interface, a local API, a background worker, storage and an isolated place to run work, all on your own machine. The included sample application is StudyState.

Not tested yet: whether StatePort comes back after a Windows reboot, working with templates on Windows, uninstalling and reinstalling, a screen-by-screen check of the whole interface, and speed and resource use. If you hit a problem, please tell me.

Exact status statement (for reviewers)

StatePort 0.1.0-alpha.20 is the current signed candidate; its installed-product rehearsal passed in an isolated simulation environment, and its public-route installation completed and came up healthy on a genuine Windows 11 host with WSL2 and stock Ubuntu 24.04. After an interactive Windows logon the installed keep-alive task held the WSL environment, and the installed product stayed reachable after the last WSL session closed on that host. Windows reboot survival and the remaining lifecycle, template, UI and efficiency checks are in progress.

Status reviewed 30 September 2026.
