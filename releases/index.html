Current software status

Alpha.26 is the current early alpha

Release label. Alpha.26 is the current public alpha, and it is an early alpha. There is no supported way back to an earlier release: you can move forward to a newer one, and data saved by one release may not be usable in another.

Alpha.26 is installed on Windows 11 with WSL2 and Ubuntu 24.04 from one command. It gives you a web interface, an API, storage and a sandbox on your own machine, and an address that only your computer can reach. It needs no account for anything except the agent actions and the chat, and for those you can use OpenCode's free models after accepting their terms. Alpha.26 (these exact signed bytes) was measured on 22 October 2026 in a local Windows 11 25H2 virtual machine (KVM, 6 GiB of memory, 4 cores) with WSL2 and a stock Ubuntu 24.04. It was installed with the versioned one-line command, which installs the same bytes as the public command. It is a virtual machine, not a laptop and not bare metal. The install took 466 seconds (about 8 minutes) once. Measured: the install; the study sample; ProjectState_Template, StudyState_Template and a third template imported by their public addresses, with their check actions run; the web interface in Microsoft Edge inside Windows (applications, catalog, approvals, runs, receipts, backup, restore as a new application, rename, settings); a service restart and a full WSL restart with data intact; uninstall, identical reinstall and purge. Not measured: agent actions and chat (OpenCode's anonymous free route had reached its usage limit from the test connection), the upgrade from Alpha.24, and Windows restart survival. With StatePort idle, WSL held about 1.2 GB of Windows memory (1.6 GB at the 95th percentile); while working about 1.1 to 1.8 GB. No swap was used. The install grew the WSL disk by about 3.8 GB and used about 3.2 GB of drive C:. The upgrade from Alpha.24 was not measured on this release. Measured: uninstall (the documented stateport uninstall) removed StatePort and kept your data; installing again brought the same applications back; purge (stateport purge, with its typed confirmation) removed the data and records. Purge keeps a copied OpenCode sign-in (see Security and privacy). Measured: the three templates were imported by their public HTTPS addresses (the default branch resolved to one exact commit), and their check actions ran, also after a service restart.

Not working yet. You cannot go back to an older release. Chat answers questions, reading the files that the template's actions say a model may read, and never changes anything. One undo exists, for the last evidence update in the study sample. A backup holds the files of one application, not its history or its conversations. There is no team, no hosted version and no supported way to reach it over a network. Agent actions and chat, the upgrade from Alpha.24 and Windows restart survival were not measured on this release. The full list is on current limitations.

Before you use StatePort

StatePort is in early alpha. Do not use it for important data.

It is built by one person, in the open. The measurement notes for the Alpha.20 runs are in the public repository under evidence/alpha20-public-install-001 (opens in a new tab), and technical release files remain available for developers and anyone who wants to check them.

Exact status statement (for reviewers)

StatePort 0.1.0-alpha.26 is the current public alpha. Its signed release index marks it a qualification candidate; it is not yet qualified. The index also declares rollback unsupported. On 22 October 2026, in a fresh Windows 11 test virtual machine (a KVM guest on a Linux workstation, not bare metal) with WSL2 and stock Ubuntu 24.04, reset to a clean snapshot, the versioned one-line command for these exact signed bytes installed StatePort 0.1.0-alpha.26 and exited 0 in 466 seconds; a second run over the finished install reported that it was already installed and changed nothing. The bundled study sample ran end to end. ProjectState_Template, StudyState_Template and a third template were imported by their public addresses and their check actions ran; all three survived a restart of the StatePort services and a full WSL restart, after which the Windows keep-alive task started Ubuntu again on its own after 68 seconds. In Microsoft Edge inside the virtual machine the interface's applications, catalog, approvals, runs, receipts, backup, restore as a new application, rename and settings worked through their real effects. Uninstall with the documented stateport command kept the data, an identical reinstall brought it back, and purge removed it. With StatePort idle, WSL held about 1.2 GB of Windows memory and no swap was used; the install grew the WSL disk by about 3.8 GB. After a cold power cycle of the virtual machine the keep-alive task started Ubuntu, but StatePort did not answer afterwards: Windows reboot survival did not pass and is being investigated. Not measured on Alpha.26: agent actions and chat (OpenCode's anonymous free route had reached its usage limit from the test connection), the upgrade from Alpha.24, and resource use on office hardware.
