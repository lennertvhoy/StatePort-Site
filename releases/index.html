Current software status

Alpha.20 is the current early alpha

Alpha.20 installs on Windows 11 with WSL2 and Ubuntu 24.04 from one command. It installed and came up healthy on seven fresh test installs, about 6.5 to 15 minutes each. All seven were virtual machines. The web interface opens without a login, and the StudyState sample (a small study-plan app) works end to end in the browser: review, approve, apply, reflect, receipt, and undo, with the saved state kept after restarts.

Not working yet: chat replies, coding-agent runs, per-application workspaces and container tools, the workbench terminal and files tools, restore from the interface, the standing-authority and updater pages, and notifications. When the last Ubuntu window closes, the product stops and comes back about three minutes after you reopen Ubuntu. Windows reboot survival is not measured, and uninstall is not documented. The full list is on current limitations.

Before you use StatePort

StatePort is in early alpha. Do not use it for important data.

It is built by one person, in the open. The measurement notes for the first runs are in the public repository under evidence/alpha20-public-install-001 (opens in a new tab), and technical release files remain available for developers and anyone who wants to check them.

Exact status statement (for reviewers)

StatePort 0.1.0-alpha.20 is the current signed candidate; its installed-product rehearsal passed in an isolated simulation environment, and its public-route installation completed and came up healthy on a genuine Windows 11 host with WSL2 and stock Ubuntu 24.04. After an interactive Windows logon the installed keep-alive task held the WSL environment, and the installed product stayed reachable after the last WSL session closed on that host. Windows reboot survival and the remaining lifecycle, template, UI and efficiency checks are in progress.

Found a bug or have feedback? Open an issue (opens in a new tab).

Do not install Alpha 2 or Alpha 3. They contain known bugs. Read the Alpha.3 technical details.
