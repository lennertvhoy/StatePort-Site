Before you use StatePort

StatePort is in early alpha. Do not use it for important data.

Alpha.7 was prepared for Windows 11 with WSL2 and Ubuntu 24.04 on x86-64. It is a candidate for a first test, not a clean-install qualification.

Technical release files remain available for developers and reviewers.

Do not install Alpha 2 or Alpha 3. They contain known bugs. Read the Alpha.3 technical details.
