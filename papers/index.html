Terms used in the papers

Stateware / StatePort
Stateware is the model. StatePort is my attempt to build it.
Template / instance
A template defines an app. An instance is your own working copy, with its own state and history.
Recorded / verified
A receipt records an operation. Verification checks a specific result. Neither shows that an answer is correct or that a person accepted it.

Read it critically

Readable files do not automatically move between machines and keep working. Local storage does not mean an outside AI provider receives no data. A recorded change is not always reversible. The practical guides explain these limits.
