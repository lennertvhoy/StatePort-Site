Three useful distinctions

Stateware / StatePort
Stateware names the proposed model. StatePort is an implementation exploring it.
Template / instance
A template defines an application. An instance is your own working copy, with its own state and history.
Recorded / verified
A receipt records an operation. Verification checks a specific result. Neither alone establishes that an answer is correct or that a person accepted it.

Read critically. Follow the evidence.

Readable files are not automatically portable execution. Local storage does not mean an external AI provider receives no data. A recorded change is not necessarily reversible. The practical guides explain these boundaries.
